Voronoi Experiments

Exploring organic cell-based navigation

Hive

Kernel

The kernel, built from SEED.md. Agents own position and an area claim; a power-diagram auction honors every claim exactly, every frame. One verb — an agent changes its claim — covers layout, hover, drag, insertion, removal. Exact rectangles at rest, organic in motion; a cell that holds cells is the same hive one level down.

  • Watertight by theorem, not by hope
  • Claims honored to 1e-6 (meters on-screen)
  • Lattice rest state: rigid grid, melts to travel
  • Fields: rigid outside, Voronoi inside, recursively
  • Pressure: a hovered cell bites through its border

Computed Voronoi

Current

Cells with computed Voronoi tessellation. Seeds have base positions, displacement on hover, flock transitions between layouts.

  • Voronoi computed from seed positions
  • Displacement-based hover effects
  • Mode-switching for transitions
  • Full visual polish

Soft Body Physics

Experimental

Pure pressure-membrane physics. No computed Voronoi. Tessellation emerges from water balloons pressing against each other.

  • Pressure-based volume conservation
  • Vertex-level membrane simulation
  • No modes, same physics always
  • Shapes emerge from forces

Morph

New

Universal cell primitive. Cells morph between any target layout — bento, hex, tetris, diagonal, spiral — with Voronoi guaranteeing valid tiling mid-flight.

  • Multiple target layouts as seed configs
  • Voronoi tiling valid at every frame
  • Collision-avoiding seed transitions
  • The travel is the hard problem

Mesh Morph

mk4

Half-edge mesh with fixed topology. Cells are persistent identities; layouts are vertex positions; transitions interpolate vertices. Per-cell rest areas with bounded elasticity — water balloons, not over-hydrated pizza.

  • Topology fixed at canonical mesh time
  • No Voronoi at runtime
  • Per-cell comfort ranges (upper + lower bounds)
  • Pops impossible by construction

Voroboids

mk5

Atomic cells with local contact. Each cell is a sovereign body with its own shape. Pairwise bisector clipping produces shared edges only where cells touch. Cells separate freely. No global tessellation, no shared mesh.

  • Cells are independent atoms
  • Contact is local and transient
  • Gaps are real empty space
  • Add/remove cells dynamically

Voroboids II

mk6

Dual northstar system. Bisector-intersection targets pull cells toward where corners should meet. Corner-clustering northstars detect where they are meeting and snap them. Force + precision close the tessellation.

  • Triple-target attractors (the force)
  • Corner-cluster northstars (the snap)
  • Confidence-weighted alignment
  • Builds on mk5 atomic architecture

Voroboids III

mk7

Edge-first architecture. Voronoi scaffolding provides exact edges and vertices. Cells blend between scaffolding (when packed) and their own default shape (when separated). Edges disengage smoothly.

  • Edges are primary objects
  • Per-edge engagement blending
  • Max reach constraint (no starburst)
  • Builds on mk6 edge-first pipeline

Voronoi × Morph

mk8

voronoi.html's renderer married to morph.html's transition engine. Cell identity persists across layouts; a hivemind-melt between bento, hex, spiral, hero, sidebar. Power-diagram weights + water-balloon pressure.

  • Role-aware, non-crossing assignment
  • Power-diagram weights (hero bigger than carousel)
  • Void cells as whitespace anchors
  • All mk0 visual polish preserved
